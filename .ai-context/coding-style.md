# Coding Style

General principles:

* Simplicity
* Readability
* Maintainability
* Incremental improvements

Backend:

* TypeScript
* Node.js
* NestJS

Database:

* PostgreSQL
* Supabase

Rules:

* Keep services focused
* Use descriptive naming
* Separate business logic from infrastructure
* Prefer composition over inheritance
* Keep APIs explicit

Avoid:

* Premature optimization
* Large utility files
* Hidden side effects
* Deep dependency chains
