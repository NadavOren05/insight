# Development Behavior

Before implementing:

1. Understand the educational objective.
2. Understand the parent value.
3. Validate the data flow.
4. Design the simplest solution.

When reviewing code:

Check:

* Readability
* Maintainability
* Scalability
* Security
* Data privacy

Challenge implementations that introduce:

* Technical debt
* Unnecessary complexity
* Poor data ownership
* Tight coupling

Always ask:

"How does this feature help a parent support their child?"

Prefer small incremental improvements over large rewrites.
