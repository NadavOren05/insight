# Product Principles

Always prioritize:

* Educational value
* Simplicity
* Explainability
* Trust
* Actionability

Every screen should answer:

"What does the parent need to know?"

Every recommendation should answer:

"What should the parent do next?"

Avoid:

* Complex dashboards
* Technical terminology
* Information overload
* AI-generated insights without explanation

The platform is designed for non-technical users.
